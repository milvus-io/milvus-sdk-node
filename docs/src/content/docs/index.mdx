---
title: Milvus Node.js SDK
---

Connect a Node.js application to Milvus or Zilliz Cloud.

```sh
npm install @zilliz/milvus2-sdk-node
```

```js
import { MilvusClient } from '@zilliz/milvus2-sdk-node';

const client = new MilvusClient({
  address: process.env.MILVUS_ADDRESS ?? 'localhost:19530',
  token: process.env.MILVUS_TOKEN,
});

try {
  const { status, data } = await client.listCollections();
  if (status.error_code !== 'Success') throw new Error(status.reason);
  console.log(data.map((collection) => collection.name));
} finally {
  await client.closeConnection();
}
```

Run the example against a local Milvus instance or set `MILVUS_ADDRESS` and `MILVUS_TOKEN` for your cluster.

- [Getting started](/milvus-sdk-node/getting-started/getting-started) covers connection, collection creation, and your first search.
- [SDK reference](/milvus-sdk-node/api-reference) documents TypeScript methods for `MilvusClient` and `HttpClient`.
- [REST API](/milvus-sdk-node/rest-api) documents four REST operations you can run from your browser.
