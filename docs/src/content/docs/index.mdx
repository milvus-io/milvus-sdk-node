Connect a Node.js application to Milvus or Zilliz Cloud.

```sh title="Terminal"
npm install @zilliz/milvus2-sdk-node
```

```js title="list-collections.mjs"
import { MilvusClient } from '@zilliz/milvus2-sdk-node';

const client = new MilvusClient({
  address: process.env.MILVUS_ADDRESS ?? 'localhost:19530',
  token: process.env.MILVUS_TOKEN,
});

try {
  const { status, data } = await client.listCollections();
  if (status.error_code !== 'Success') throw new Error(status.reason);
  console.log(data.map((collection) => collection.name));
} finally {
  await client.closeConnection();
}
```

Run `node list-collections.mjs` against local Milvus, or set `MILVUS_ADDRESS` and `MILVUS_TOKEN` for your cluster.
