Use `MilvusClient` on Node.js servers with gRPC support. Choose `HttpClient` for HTTP-only environments such as Cloudflare Workers and Vercel Edge, or when a proxy requires REST.

## Choosing the Right Client

| Decision                           | MilvusClient (gRPC)                                                                                 | HttpClient (REST)                                                                        |
| ---------------------------------- | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Protocol                           | gRPC over HTTP/2                                                                                    | Milvus REST v2 over HTTP with JSON                                                       |
| Request field casing               | snake_case, such as `collection_name`                                                               | camelCase, such as `collectionName`                                                      |
| Serverless and edge support        | Use in Node.js runtimes that support gRPC connections                                               | Use in Fetch-capable runtimes, including HTTP-only serverless and edge environments      |
| Streaming and gRPC-only admin RPCs | Supports replication and WAL streams, plus proxy and telemetry administration                       | Supports REST management operations and returns JSON responses                           |
| Response and error handling        | Inspect `error_code` on a status or `status.error_code` on a result. Transport failures can reject. | Inspect `code` where the REST response provides it. Non-2xx responses throw `HttpError`. |

Set the REST client's `endpoint` to your cluster origin. The SDK appends `/v2`. For a custom `baseURL`, include the full versioned URL ending in `/v2`.

## Serverless Platforms

### Vercel

Deploy to Vercel serverless functions with minimal configuration.

**Quick Start:**

```javascript
// api/search.js
import { HttpClient } from '@zilliz/milvus2-sdk-node';

let client;

function getClient() {
  if (!client) {
    client = new HttpClient({
      endpoint: process.env.MILVUS_ENDPOINT,
      token: process.env.MILVUS_TOKEN,
      timeout: 10000,
    });
  }
  return client;
}

export default async function handler(req, res) {
  const milvusClient = getClient();
  const results = await milvusClient.search({
    collectionName: 'my_collection',
    data: req.body.vectors,
    limit: 10,
  });
  res.status(200).json({ results });
}
```

**Learn more:** [Vercel Deployment Guide](/milvus-sdk-node/advanced/vercel/)

### Cloudflare Workers

Deploy to Cloudflare Workers for edge computing.

**Quick Start:**

```javascript
// worker.js
import { HttpClient } from '@zilliz/milvus2-sdk-node';

export default {
  async fetch(request, env) {
    const client = new HttpClient({
      endpoint: env.MILVUS_ENDPOINT,
      token: env.MILVUS_TOKEN,
      timeout: 25000,
    });

    const results = await client.search({
      collectionName: 'my_collection',
      data: [
        /* vectors */
      ],
      limit: 10,
    });

    return new Response(JSON.stringify({ results }), {
      headers: { 'Content-Type': 'application/json' },
    });
  },
};
```

**Learn more:** [Cloudflare Workers Deployment Guide](/milvus-sdk-node/advanced/cloudflare/)

### AWS Lambda

Deploy to AWS Lambda for scalable serverless functions.

**Quick Start:**

```javascript
// index.js
import { HttpClient } from '@zilliz/milvus2-sdk-node';

let client;

function getClient() {
  if (!client) {
    client = new HttpClient({
      endpoint: process.env.MILVUS_ENDPOINT,
      token: process.env.MILVUS_TOKEN,
      timeout: 25000,
    });
  }
  return client;
}

export const handler = async (event) => {
  const milvusClient = getClient();
  const results = await milvusClient.search({
    collectionName: 'my_collection',
    data: JSON.parse(event.body).vectors,
    limit: 10,
  });

  return {
    statusCode: 200,
    body: JSON.stringify({ results }),
  };
};
```

**Learn more:** [AWS Lambda Deployment Guide](/milvus-sdk-node/advanced/aws-lambda/)

## Traditional Server Deployment

### Node.js/Express

For traditional Node.js servers, you can use either client:

```javascript
// Using gRPC Client (Recommended)
import { MilvusClient } from '@zilliz/milvus2-sdk-node';

const client = new MilvusClient({
  address: 'localhost:19530',
  token: 'your-token',
});

await client.connectPromise;

// Using HTTP Client
import { HttpClient } from '@zilliz/milvus2-sdk-node';

const client = new HttpClient({
  endpoint: 'http://localhost:19530',
  token: 'your-token',
});
```

### Docker

Deploy in Docker containers:

```dockerfile
FROM node:20-alpine

WORKDIR /app

COPY package*.json ./
RUN npm install

COPY . .

EXPOSE 3000

CMD ["node", "index.js"]
```

Always use environment variables for sensitive configuration:

```bash
# .env

MILVUS_TOKEN=your-api-token
```

## Platform Comparison

| Platform           | Client Type  | Timeout Limit            | Best For                            |
| ------------------ | ------------ | ------------------------ | ----------------------------------- |
| Vercel             | HTTP         | 10s (Hobby), 60s (Pro)   | Next.js apps, static sites          |
| Cloudflare Workers | HTTP         | 30s (free), 15min (paid) | Edge computing, global distribution |
| AWS Lambda         | HTTP         | Up to 15 minutes         | Enterprise serverless               |
| Traditional Server | gRPC or HTTP | No limit                 | Long-lived applications             |

## Common Patterns

### Client Reuse

Reuse client instances to improve performance:

```javascript
let client;

function getClient() {
  if (!client) {
    client = new HttpClient({
      endpoint: process.env.MILVUS_ENDPOINT,
      token: process.env.MILVUS_TOKEN,
    });
  }
  return client;
}
```

### Error Handling

Always handle errors appropriately:

```javascript
try {
  const results = await client.search({
    /* ... */
  });
  return { success: true, results };
} catch (error) {
  console.error('Milvus error:', error);
  return {
    success: false,
    error: error.message,
    status: error.status || 500,
  };
}
```

### Timeout Configuration

Set timeouts based on platform limits:

```javascript
const client = new HttpClient({
  endpoint: process.env.MILVUS_ENDPOINT,
  token: process.env.MILVUS_TOKEN,
  timeout: 10000, // Adjust based on platform
});
```
